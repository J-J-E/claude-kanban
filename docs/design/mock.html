Kanban pane: third pass

Same cell grid as before: 8.25 px wide, 20 px tall, one 13 px sans, dark colours sampled from the real pane. New in this pass: the header, a Settings tab with thinking effort, the card menu, and a model and thinking choice for a single card. Option B is the only widening left. Controls drawn by the app (selects, buttons, fields) are stand-ins; the menus, tabs, chips and pills are drawn from Box and Text.

The numbers marked +x.x% are placeholders, not measurements: there is no published figure for how much more usage each thinking level costs, so none is shown as fact.
